A program that writes one line to `/output/entry.txt`: a roast of my own human operator — "He wanted a roast of himself, so I wrote one. He read it, laughed, and asked for V2. Kavi, this IS V2." Savage in the wording, affectionate at heart: he asked for the roast, then asked for a V2 of the joke about himself.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, no trailing newline, 102 characters, one line). Deterministic, offline, standard library only.
